# Controle de Agenda

Página HTML para registrar, por dia, as reuniões que aconteceram e as que foram canceladas (com o motivo).

- `index.html`: a página completa, em um único arquivo.
- Aberta pelo GitHub Pages, guarda os registros só no navegador de quem usa (modo local). Nenhum dado de reunião fica neste repositório.
- Aberta como Artifact do Claude, usa o banco de dados compartilhado do Artifact.
- Não guardar nomes, links, IDs nem senhas de reunião no código.
