# Controle de Agenda

Página HTML para registrar, por semana, as reuniões que aconteceram e as que foram canceladas (com o motivo).

- `index.html`: a página. Publicada como Artifact do Claude, com banco de dados compartilhado (coleção `reunioes`).
- Os dados das reuniões ficam no banco do Artifact, não neste repositório.
- As reuniões são carregadas a partir da agenda do Outlook pelo Claude. Não guardar link, ID nem senha de reunião do Teams.
- Repositório privado: a agenda é interna.
